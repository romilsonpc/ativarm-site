01 · Serviços

O que a Ativa RM faz

Atendimento direto com quem projeta e escreve o código, do banco de dados à infraestrutura.

IA generativa em sistemas existentes

Integração da API do Claude a aplicações já em uso: extração de dados de documentos, classificação, apoio à redação e análise de contratos, com registro de custo e de uso por chamada.

Desenvolvimento e modernização

Evolução de sistemas em Delphi e C#/.NET com SQL Server, e novos serviços em Python/FastAPI. O sistema antigo continua funcionando enquanto ganha recursos novos. Inclui relatórios gerados a partir de consultas e automações como envio de emails e notificações.

Integrações

Conexão com APIs bancárias, sistemas financeiros de terceiros, telefonia VoIP, atendimento via Chatwoot, notificações e assinatura digital ICP-Brasil.

Infraestrutura

Serviços em Docker sobre Linux, migração de ambientes Windows, banco de dados, desempenho de consultas e segurança da informação.

02 · Projetos

IA em produção, dentro de um sistema real

A maior parte dos projetos abaixo foi construída no SGI, uma plataforma de gestão imobiliária e de processos jurídicos usada todos os dias. O último é a modernização de outro sistema, do setor de cartórios. Nomes de clientes e de instituições foram omitidos.

Extração

Leitura de contratos e documentos em PDF

A IA lê o documento e preenche o cadastro: partes envolvidas, múltiplos endereços, valores e datas. O usuário revisa em vez de digitar.

  • Claude API
  • Delphi
  • SQL Server

Conferência

Marcação automática do trecho de origem no PDF

Cada campo extraído volta marcado no documento original, com página e posição. Funciona também em PDFs digitalizados, com OCR e busca aproximada de texto.

Quem confere vê de onde cada valor saiu, sem procurar no documento.

  • Python/FastAPI
  • PyMuPDF
  • Tesseract OCR
  • Docker

Importação

Robô de importação de planilhas de débito

Extratos de consórcio e de financiamento chegam em PDF, cada credor com um layout. A IA extrai parcelas vencidas e a projeção de pagamento em formato estruturado, e o sistema grava direto nas prestações. PDFs com camada de texto ilegível são lidos como imagem.

Custo médio de cerca de US$ 0,08 por documento.

  • Claude API
  • Prompts versionados em banco
  • Delphi

Classificação

Classificação automática de documentos

Arquivos recebidos são identificados por tipo com um dicionário de regras e limite mínimo de confiança. Três modos de operação: automático, semiautomático e somente relatório.

  • Claude API
  • Regras em SQL

Planilhas

Importação de Excel com mapeamento dinâmico

O mapeamento de colunas fica em banco e se ajusta a cada planilha. O sistema localiza os documentos pelo número do contrato, converte para PDF, classifica com IA e anexa ao processo.

  • Delphi
  • Automação de documentos
  • Claude API

Redação

Corretor de textos e analisador de contratos

Ferramenta acionada por atalho de teclado em qualquer tela, com correção ortográfica e análise de contratos. Os prompts são administrados pela própria equipe, sem alterar o programa.

  • Claude API
  • Gestão de prompts

Dados

Parametrização por autoaprendizado e detecção de anomalias

O sistema sugere parâmetros faltantes a partir do histórico e aponta valores fora do padrão por análise estatística. Duplicidades de arquivos são detectadas por comparação de hash SHA-256.

Uma análise em lote que levava 1 min 32 s passou a rodar em 12 s.

  • SQL Server
  • Estatística (IQR)
  • SHA-256

Base

Camada única de integração com IA

Todas as chamadas passam por um componente que registra uso e custo, detecta respostas cortadas e trata o retorno antes de chegar à tela. É o que permite acrescentar novos usos de IA com segurança.

  • Claude API
  • Log de uso e custo
  • Processamento em segundo plano

Modernização

Atualização da plataforma de um fundo do setor de cartórios

API e sistema web de um fundo ligado a cartórios de registro, atualizados com foco em segurança: credenciais expostas no código foram removidas, o código fora de escopo foi enxugado e o front-end foi refeito em tecnologia atual, com telas de pagamentos, pagadores, beneficiários, cálculo do fundo, controle de acesso e relatórios.

3.311 arquivos migrados, cerca de 70 mil linhas de código obsoleto removidas e migração de dados executada em 14 cartórios, com proteção contra duplicidade.

  • Segurança da informação
  • Migração de banco de dados
  • Novo front-end
  • API
